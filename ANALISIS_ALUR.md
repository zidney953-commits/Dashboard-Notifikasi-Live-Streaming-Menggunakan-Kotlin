# Alur Sistem

Pengelola memulai live streaming -> backend menerima/periksa status live -> data status disimpan -> sistem mengirim notifikasi push -> aplikasi Flutter menerima notifikasi -> pengguna membuka dashboard -> pengguna melihat status live dan membuka detail streaming.

Versi prototype saat ini menggunakan data lokal di Dart. Belum terhubung Firebase atau backend produksi.
